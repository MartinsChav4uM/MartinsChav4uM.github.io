Política de privacidade

Versão de 06/11/2026. Vale para este site e para o aplicativo Gestão Fotográfica (versão de teste e versão completa).

Em resumo: não coletamos nenhum dado seu. O site não usa cookies, formulários, ferramentas de análise ou de publicidade. O app guarda tudo só no seu computador e nunca envia seus dados para nós. As únicas conexões externas são com o GitHub, para baixar o instalador e, na versão de teste, para conferir a versão ao abrir. Estão explicadas abaixo.

1. O que acontece quando você visita este site

  • Sem cookies e sem rastreamento. O site não grava cookies e não usa Google Analytics, pixels de redes sociais nem ferramentas parecidas. Por isso não há aviso de cookies: não há nada para você aceitar ou recusar.
  • Sem formulários. O site não pede nome, e-mail, telefone nem qualquer outro dado.
  • Fontes e imagens do próprio site. As fontes de letra ficam hospedadas aqui mesmo. A página não busca nada no Google nem em outras empresas ao carregar.
  • Um registro técnico no navegador. A animação de abertura aparece só uma vez por visita. Para isso, o navegador guarda a marca “gf-splash” na memória da aba (sessionStorage), que some quando a aba é fechada. Ela não identifica você e não é enviada para ninguém.
  • Hospedagem. Como em qualquer site, o serviço que hospeda estas páginas recebe o endereço IP e os dados técnicos do navegador para entregá-las, e pode guardar esses registros por segurança, conforme a política dele.
  • Número da versão e download. Para mostrar a versão mais recente e levar você ao instalador certo, a seção de download consulta o GitHub (GitHub, Inc., Estados Unidos), onde o instalador fica publicado. Nessa consulta, e no download, o GitHub recebe o seu endereço IP e os dados técnicos do navegador, como acontece ao abrir qualquer site. Veja a declaração de privacidade do GitHub.

2. O que o aplicativo faz com dados

  • Tudo fica no seu computador. Vendas, despesas, clientes, catálogo de fotos, miniaturas e configurações ficam na pasta %LocalAppData%\Fotografo do seu Windows. Nós não temos acesso a esses dados, e o app não os envia para lugar nenhum. Os backups vão só para onde você escolher.
  • Consulta de versão (só na versão de teste). Ao abrir, a versão de teste faz um pedido ao GitHub para saber qual é a versão mais recente e a hora certa. O pedido leva só o número da versão do app. Nenhum dado de vendas, clientes ou fotos vai junto. O GitHub recebe o endereço IP do computador, como em qualquer acesso à internet. A versão completa não faz essa consulta.
  • Controle do período de teste. A versão de teste grava, no registro do Windows e na pasta de dados, a data da primeira abertura e a da última, com uma assinatura contra edição. Esses registros não contêm dados pessoais e servem só para contar os 30 dias.
  • Logs. Erros do app são gravados em arquivos de texto na pasta de dados, no seu computador, para ajudar no suporte se você mesmo resolver enviá-los. Nada é enviado de forma automática.

3. Os dados dos seus clientes

Se você cadastra clientes no app (nome, telefone, e-mail, CPF), quem decide sobre esses dados é você. Para a LGPD, você é o controlador deles, e o app é só a ferramenta, que fica no seu computador. Use esses dados só para a finalidade combinada com cada cliente, guarde só o necessário, mantenha o computador e os backups protegidos e atenda os pedidos dos seus clientes (acesso, correção, exclusão). O app ajuda: dá para editar e excluir cadastros e apagar todos os dados em Configurações › Zona de risco.

4. Base legal

Como não coletamos dados pessoais, quase não há tratamento por nossa parte. Os registros técnicos de acesso (endereço IP) que a hospedagem e o GitHub recebem servem para entregar o site e o instalador, e para a segurança. Eles se apoiam no legítimo interesse (art. 7º, IX, da LGPD) e, quando for o caso, no cumprimento de obrigação legal (art. 15 do Marco Civil da Internet, Lei 12.965/2014). O GitHub fica nos Estados Unidos. A transferência internacional decorre do uso desse serviço e segue as garantias que ele oferece (art. 33 da LGPD).

5. Seus direitos

A LGPD (art. 18) garante a você, entre outros direitos: saber se tratamos dados seus; acessar, corrigir, anonimizar ou eliminar dados; pedir informações sobre compartilhamento; e revogar consentimentos. Você também pode reclamar na Autoridade Nacional de Proteção de Dados (ANPD).

6. Crianças

O app e o site são feitos para profissionais de fotografia e não se destinam a menores de 18 anos.

7. Mudanças nesta política

Se alguma coisa mudar, por exemplo se um dia passarmos a ter cadastro ou pagamento pelo site, esta página será atualizada antes, com a nova data no topo. Mudanças importantes também serão avisadas na página inicial.
